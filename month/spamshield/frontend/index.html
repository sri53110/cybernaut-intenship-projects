              What happens to a message

              1. Clean

                HTML is stripped. Links, addresses, phone numbers, money and digits become placeholder tokens, and SHOUTING or many exclamation marks are flagged.

              2. Weigh

                Words and word pairs are scored with TF-IDF, so rare, telling phrases count for more than common ones.

              3. Classify

                Naive Bayes, Logistic Regression and a Support Vector Machine each return a probability of spam.

              4. Explain

                The words that moved the score are listed, so a blocked message never needs to be a mystery.

              Use it from your own app

              The same service powers this page. Send JSON, get a verdict.

              curl -X POST http://localhost:8000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"subject": "Final notice", "text": "Verify your account at http://secure-login.top", "model": "svm"}'
              {
  "label": "spam",
  "spam_probability": 0.97,
  "confidence": "high",
  "spam_signals": [{ "term": "urltoken", "score": 0.41 }],
  "votes": { "naive_bayes": 0.99, "logistic_regression": 0.96, "svm": 0.97 }
}

              SpamShield classifies text on this server. Nothing you paste is stored.
